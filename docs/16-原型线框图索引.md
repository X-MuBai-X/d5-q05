# 16 · 原型线框图索引（题目 05）

> 原型本体是**服务端渲染的真实页面**（`internal/httpapi/web/templates/*.html`），
> 跑起来就是原型：`http://127.0.0.1:8080/login`、`/ops`、`/admin`、`/app`。
>
> 本目录下的 SVG 是**同一结构的静态副本**，由 `scripts/gen-prototype-svg.py`
> **从模板的真实区块、字段与文案生成**，并在图上标注对应的模板文件与行号，
> 用于文档、PPT 或视频里快速展示页面构成；**不作为原型本体**，
> 两者不一致时以模板与运行实例为准。
>
> 重新生成：`python scripts/gen-prototype-svg.py`（无需额外依赖，输出为纯文本 SVG）。

## 2. 图上出现的关键口径（与题面对应）

| 图上元素 | 含义 | 依据 |
|---|---|---|
| 顶部导航「运营台 / 租户管理台 / 应用调用台」 | 三个角色各自的入口；越权访问会被 303 跳走 | `layout.html:40-44` |
| 右上角「用户名（角色 / 租户）」 | 身份与租户归属由**服务端会话**决定，请求参数改不了 | `layout.html:45-47` |
| 绿色 `.msg` / 红色 `.err` 提示条 | 操作成功 / 4xx 及可纠正错误，出现在内容区顶部 | `layout.html:50-51` |
| UTC 自然日日期选择器 | 日额度与日终统计按 **UTC 自然日**归集 | `ops.html:6`、`admin.html:6`、`app.html:6` |
| KPI：日额度 / 成功量 / 处理中 / 剩余额度 / 租户编号 | 租户级共享额度，处理中计入占用 | `admin.html:15-19` |
| 凭证表「最多 2 个凭证」 | 题面预置条件与 R1 约束 | `admin.html:24` |
| 终态标签（成功 / 失败 / 超时 / 被拒绝） | 五类终态分列；迟到结果只进诊断区 | `app.html:41`、`ops.html:102` |
| 「被拒绝的尝试不占用请求编号」 | 确认结论 Q7：额度提升后可用同一编号重试 | `admin.html:89` |

## 4. 生成与校验方式

| 项 | 说明 |
|---|---|
| 生成命令 | `python scripts/gen-prototype-svg.py`（纯标准库，无第三方依赖；输出为纯文本 SVG） |
| 数据来源 | `internal/httpapi/web/templates/*.html` 的真实区块、字段名、列名与文案；图上标注来源模板与行号 |
| 确定性 | 同一输入重复生成的字节完全一致（已实测：连续两次生成后工作区无差异） |
| 合法性 | 8 张均以 XML 解析器校验通过（`xml.dom.minidom.parse`） |
| 口径约定 | 依据 `AGENTS.md` §8 第 7 条：派生产物必须与本体同源且不得冒充本体 |

> 图中数值为**演示态示意值**（如日额度 20、成功量 5），取自真实业务口径下的自洽样例，
> 用于展示页面结构与字段含义，**不是**某次真实运行的结果；
> 真实运行结果以 `evidence/` 下的日志与报表为准。
